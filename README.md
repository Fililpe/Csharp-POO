# Csharp-POO

Exercícios da disciplina de Programação Orientada a Objetos (POO) do curso de Cibersegurança da CESAR School, semestre 2026.2.

## Requisitos

- .NET SDK 10.0

## Como executar

Clonar o repositório:

```bash
git clone https://github.com/Fililpe/Csharp-POO.git
cd Csharp-POO
```

Rodar um projeto específico:

```bash
dotnet run --project "Exercicio 01 - IMC"
```

Compilar tudo de uma vez:

```bash
dotnet build
```

## Observações

Os programas usam top-level statements, sem declaração explícita de `class Program` ou `Main`.

Nos exercícios que leem números decimais, o separador esperado é o da cultura configurada na máquina. Em português do Brasil, use vírgula.
